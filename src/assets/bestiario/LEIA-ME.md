# Arte do bestiário

Solte aqui a arte de cada criatura com o **id** dela no nome do arquivo:

- `goblin.webp`, `young-red-dragon.webp`, `owlbear.webp`…
- Formatos: `.webp` (recomendado), `.png` ou `.jpg`.
- Tamanho: retrato **4:5** (ex.: 800×1000), fundo escuro liso, criatura centralizada.

O app pega sozinho: o card do bestiário, a iniciativa, a busca e os peões
do mapa passam a usar a arte. Sem arquivo, aparece o emblema do tipo.

A lista completa de ids, com um prompt pronto para cada criatura, está em
`docs/ARTE-BESTIARIO.md`. O mestre ainda pode trocar a foto de qualquer
criatura só para a mesa dele (botão **Personalizar** no bestiário).
